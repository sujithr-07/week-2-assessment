# Week 2 Assessment

This repository contains four machine-learning tasks:

- **[task 1](./task%201/)** — Covers classification concepts, train/validation/test splits, overfitting, cross-validation, and data leakage. The notebook uses the Telco customer churn dataset; `task1.py` demonstrates similar ideas with the breast cancer dataset.
- **[task 2](./task%202/)** — Builds an end-to-end loan approval pipeline with feature engineering, preprocessing, a Random Forest classifier, evaluation, and predictions. The script creates sample data and saves the fitted pipeline.
- **[task 3](./task%203/)** — Analyzes loan data with classification models, feature importance, regression, and K-means clustering.
- **[task 4](./task%204/)** — Analyzes Telco customer churn using Logistic Regression, Random Forest, and XGBoost, including model tuning and evaluation; also explores predicting total charges.

Each task folder contains its notebook or script, with the related datasets and generated outputs where applicable. Install the packages listed in `requirements.txt` before running the code.
